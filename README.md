# 🚗 Автомобільний парктронік на Arduino Mega 2560

Проект ультразвукового парктроніка для автомобіля на базі контролера **Arduino Mega 2560**, ультразвукового датчика відстані **HC-SR04** та п'єзоелектричного зумера (бузера).

Система вимірює відстань до перешкоди та інформує водія за допомогою звукових сигналів різної частоти й переривчастості: чим ближче перешкода — тим частіше лунають звукові імпульси.

---

## 📋 Основні можливості

* **Точне вимірювання відстані:** від 2 см до 400 см за допомогою ультразвукового луна-сигналу.
* **Багаторівнева акустична індикація:**
  * **> 100 см:** Безпечна зона — звуковий сигнал відсутній.
  * **50 – 100 см:** Попереджувальна зона — повільний переривчастий сигнал.
  * **20 – 50 см:** Зона наближення — частий переривчастий сигнал.
  * **< 20 см:** Критична зона — безперервний сигнал тривоги.
* **Моніторинг через Serial:** Виведення поточної відстані в сантиметрах у реальному часі.

---

## 🛠 Обладнання та компоненти

| Компонент | Кількість | Примітка |
|---|---|---|
| **Arduino Mega 2560** | 1 шт. | Основна плата мікроконтролера |
| **Ультразвуковий модуль HC-SR04** | 1 шт. | Датчик вимірювання відстані |
| **П'єзобузер (Piezo Buzzer)** | 1 шт. | Пасивний або активний бузер 5V |
| **Резистор 220 Ом** | 1 шт. | Для обмеження струму бузера (за потреби) |
| **Макетна плата (Breadboard)** | 1 шт. | Для швидкого монтажу |
| **З'єднувальні провідники** | 1 комплект | Провідники Dupont |

## 🔌 Схема підключення (Pinout)

### 1. Датчик HC-SR04 → Arduino Mega 2560
* **VCC** → `5V`
* **Trig** → Цифровий піновий вихід `9`
* **Echo** → Цифровий піновий вхід `8`
* **GND** → `GND`

### 2. П'єзобузер → Arduino Mega 2560
* **Позитивний контакт (+)** → Цифровий піновий вихід `10` (через резистор 220 Ом)
* **Негативний контакт (-)** → `GND`

🚀 Інструкція зі збірки та запуску
Завантажте та встановіть Arduino IDE.

Підключіть Arduino Mega 2560 до ПК за допомогою USB-кабелю.

У меню Arduino IDE оберіть плату:
Tools -> Board -> Arduino AVR Boards -> Arduino Mega or Mega 2560

Оберіть ваш COM-порт у Tools -> Port.

Зберіть схему відповідно до розділу Схема підключення.

Вставте C++ код у редактор та натисніть Upload (Завантажити).

Відкрийте Serial Monitor (Ctrl + Shift + M), встановивши швидкість 9600 baud, щоб бачити дані вимірювання в сантиметрах.
